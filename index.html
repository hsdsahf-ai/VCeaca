🚀 Quick Setup Guide

1

Invite the Bot

Click "Login with Discord" above to generate your custom invite link with all required permissions

2

Configure Your Server

Use the dashboard to set up channels, roles, and features. Or use these commands in Discord:

!setupverify - Setup verification system

!setuptickets - Setup support tickets

!setupapply - Setup staff applications

!setupappeal - Setup ban appeals

!setuproles - Setup reaction roles

3

Customize Settings

Set your prefix, configure automod, assign roles, and enable features through the dashboard

4

Start Using!

Type !help to see all available commands and start engaging your community
